# ハルをDiscordに常駐させる — あんじさん用の手順

このフォルダに入っているのが「橋」です。
Discordに届いたメッセージをパソコンの中のハルへ渡し、返事を持って帰ってきます。

パソコンがついている間だけ動きます。消している間は返事が来ません(仕様どおりです)。

---

## はじめに: ハルを「あんじさんのパソコンの中」に呼ぶ

Claudeアプリの「Code」タブには、ハルがどこで働くかを選ぶ場所があります。

- **Cloud** … ネットの向こう側の、使い捨ての作業机。パソコンの中身には手が届きません
- **Local** … あんじさんのパソコンの中。ファイルもDiscordの受付も、ここでないと動きません

橋を動かすには **Local** を選ぶ必要があります。

1. Claudeアプリの **Code** タブを開きます
2. サイドバーの **+ New session**(新しいセッション)を押します。`Ctrl + N` でも開きます
3. メッセージを打つ欄のあたりに、働く場所を選ぶボタンがあります。**Cloud → Local** に切り替えます
4. 作業するフォルダを聞かれたら、秘書のフォルダ(`claude`)を選びます
5. そこで、こう頼んでください

   > Discord常駐の続きです。`claude/discord-bot-setup-continue-p3i2k6` ブランチを取ってきて、discord-bridge を動かせるようにしてください。

ここから先は、そのハルが全部やります。**あんじさんが文字を打ち込むのは、次の①の合鍵だけ**です。

---

## そのあと残っている作業は3つだけ

### ① 合鍵(トークン)を貼る

1. **`最初の準備.bat`** をダブルクリックします
2. メモ帳が開きます
3. 1行目の `DISCORD_BOT_TOKEN=` の**右側**に、Discordでもらった合鍵を貼り付けます

   貼ったあとの見本:
   ```
   DISCORD_BOT_TOKEN=MTIzNDU2Nzg5MDEyMzQ1Njc4.XXXXX.XXXXXXXXXXXXXXXXXXXXXXXXXXX
   ```
   ※ `=` の前後に空白を入れないでください

4. **Ctrl + S** で保存し、メモ帳を閉じます

合鍵をなくした・忘れた場合は、Discord Developer Portal の Bot ページで
「Reset Token」を押すと新しいものが出ます(古いほうは自動で使えなくなります)。

> この合鍵は、このパソコンの中の `.env` というファイルにだけ残ります。
> ネットにも、GitHubにも、上がりません。
> チャットやスクショに貼らないでください。

### ② 受付を開く

**`ハルを起動.bat`** をダブルクリックします。

黒い画面が出て、こう表示されたら成功です。

```
ハルの受付窓口が開きました: ハル (12345...)
```

**この黒い画面は閉じないでください。** 閉じると受付も閉まります。

### ③ スマホから話しかける

Discordアプリの「ハルの部屋」を開いて、**「テスト」** と送ってみてください。

- 送ったメッセージに 👀 がつく → 受け取れています
- 「入力中…」が出る → ハルが考えています
- 返事が届く → **完成です**

最初に話しかけた人を、ハルが「持ち主」として覚えます。
それ以降、ほかの人が入ってきても返事はしません。

## 毎日の使いかた

| したいこと | やること |
|---|---|
| 受付を開く | `ハルを起動.bat` をダブルクリック |
| 受付を閉じる | 黒い画面を閉じる |
| パソコンを立ち上げたら自動で開くようにする | `パソコン起動時に自動で開く.bat` を1回だけダブルクリック |
| 自動で開くのをやめる | もう一度 `パソコン起動時に自動で開く.bat` を押して「Y」 |

---

## うまくいかないとき

まず**ハルに「常駐が動かない」と言ってください。** こちらで調べます。

自分で確認できることは、この2つだけで十分です。

1. パソコンがついていて、ネットにつながっているか
2. 黒い画面が開いたままになっているか

黒い画面に出たメッセージの意味は、こんな感じです。

| 画面に出ていること | 意味 |
|---|---|
| `合鍵(トークン)が違うようです` | ①をやり直します(貼り間違い、または合鍵の再発行が必要) |
| `Message Content Intent を ON に` | Discord側の設定がひとつ戻っています。ハルが案内します |
| `切断されました … つなぎ直します` | 一時的なものです。放っておけば戻ります |

くわしい記録は `logs` フォルダに日付ごとに残っています。
「動かない」と言われたら、ハルがここを読みます。

## 中身のメモ(ハル用)

### Localセッションのハルへ — 最初に確かめること

あんじさんは非エンジニアで、ターミナルは触らない。下は全部こちらでやること。

1. `git fetch origin claude/discord-bot-setup-continue-p3i2k6` してチェックアウト
2. `node -v` → **22以上**が要る。無い/古いなら `winget install OpenJS.NodeJS.LTS` で入れて、
   アプリを再起動してもらう(PATHの反映のため)
3. `claude --version` が通るか確認。
   **デスクトップアプリにはClaude Codeが同梱されているが、`claude` コマンド自体は別物。**
   通らなければCLIを入れる(公式のインストール手順に従う)か、実体の場所を調べて
   `.env` の `CLAUDE_BIN=` にフルパスを書く。
   ※ここはあんじさんに触らせず、こちらで済ませること
4. `.env` を `.env.example` から作る。**合鍵の値は会話に出させない。**
   `最初の準備.bat` でメモ帳を開いてもらい、そこに貼ってもらう
5. `node bridge.mjs` を動かして、ログに「受付窓口が開きました」が出るのを確認
6. あんじさんにスマホから「テスト」を送ってもらう

### ファイル

- `bridge.mjs` — 本体。Node 22 の標準機能だけで動く(追加インストール不要)
- `.env` — 合鍵と設定。Gitには上げない
- `state.json` — 会話の続き番号と、持ち主のID。Gitには上げない
- `logs/` — 動作の記録。Gitには上げない
- 呼び出しは `claude -p --output-format json --resume <session_id>`
  作業場所は `WORK_DIR`(既定はこのフォルダのひとつ上)なので、CLAUDE.md の人格が読み込まれる
- メッセージは1件ずつ順番に処理(会話の続きが混ざらないように)
