# 秘書「ハル」

あんじさん専用の、秘書リポジトリです。

秘書の人柄・仕事の進め方・守ることは、すべて **[`CLAUDE.md`](CLAUDE.md)（指示書）** に書いてあります。
Claude はここで仕事を始めるとき、まずその指示書を読んでから動きます。

## 使い方

このリポジトリを開いて、話しかけるだけです。アプリもビルド手順もありません。

## いまのおもな仕事

**調べ物と比較。** 条件を確認 → 候補を3つほどにしぼる → 比較表にまとめる →
おすすめを1つ、理由つきで添えます。買う・予約する・申し込むボタンは押しません。

## 指示書の育て方

「これ、次から気をつけて」と伝えたことは、秘書が指示書に書き足していきます。
規則は、困ったことが起きるたびに1行ずつ増えれば十分です。
