## 🌊 全国波情報(surf.html)

全国17の主要サーフスポット(苫小牧〜沖縄・日本海側含む)の波情報を1ページにまとめたものです。
ブラウザで開くたびに [Open-Meteo](https://open-meteo.com/) の海洋気象API(無料・キー不要)から最新の予報を取得します。

- **サイズ** — スネ〜ダブル以上のサーフ表記 + 波高(m)、7日間の週間バー
- **波数** — うねりの周期と風波の割合から「少なめ / 普通 / 多め」を推定
- **うねりの向き・周期** — 方位と矢印、平均周期(秒)
- **満潮・干潮時間** — 潮位モデルから抽出。展開すると1日の潮位カーブを表示
- **風** — 午前/午後の風向・風速と、ビーチの向きから判定したオフ/オンショア
- 地域(関東・日本海など)と日付(今週7日分)で絞り込み。ライト/ダーク対応、スマホ対応
- データは1時間 localStorage にキャッシュ。`?demo=1` を付けるとオフラインのデモデータで表示

※ 沖合の有義波高にもとづく目安です。実際のブレイクサイズはポイントの地形で変わります。

# ⏱ タイムロガー

自分専用のタイムロガーです。毎日の行動記録をブラウザに保存し、履歴としてずっと残せます。
サーバー不要の単一 HTML ファイル(`index.html`)で動作します。

## 機能

- **▶ 今から開始 / ■ 終了** — ワンタップで行動の記録を開始・終了(ストップウォッチ方式)
- **並行記録** — 複数の行動を同時に走らせて、それぞれ個別に終了・メモ追加できる(例: 「移動」しながら「読書」)
- **よく使う行動ボタン** — タップするだけで記録開始。ボタンは画面から追加・編集・削除できる
- **時間を指定して追加** — 後からまとめて記録したいときの手動入力
- **カテゴリ・メモ** — 行動にカテゴリやメモを付けられる(入力候補は過去の記録から自動表示)
- **今日の記録** — 今日のタイムラインとカテゴリ別の集計
- **履歴** — 全記録を日付ごとに閲覧。キーワード検索・月での絞り込み対応
- **編集・削除** — 記録した内容は後から修正可能
- **エクスポート / インポート** — JSON(バックアップ・端末間の移行用)と CSV(Excel などでの分析用)

## データの保存について

記録は **ブラウザの localStorage** に保存されます。つまり:

- サーバーにデータは送信されません(完全に自分専用)
- **同じブラウザ・同じ端末** でアクセスすれば記録は残り続けます
- ブラウザのサイトデータを削除したり、端末を変えると記録は消えます

⚠️ 大切な記録を守るため、**「データ管理」タブから定期的に JSON エクスポート** してバックアップを取ってください。別の端末に移るときは、そのファイルをインポートすれば記録が統合されます(重複しません)。

## ウェブで公開する(GitHub Pages)

1. このリポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」にする
3. **Branch** で公開したいブランチ(例: `main`)と `/ (root)` を選んで **Save**
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` でアクセスできます

スマホのブラウザで開いて「ホーム画面に追加」すると、アプリのように使えます。

## ローカルで使う

`index.html` をブラウザで開くだけで動きます。
